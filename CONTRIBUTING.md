# Enderdash feedback

This repository tracks product defects and feature requests. It does not contain the application source.

## Report a defect

1. Search open and closed issues.
2. Use the bug report form.
3. Name the affected dashboard, agent, client library, shop, deployment manifest, or chart.
4. Include exact versions, minimal steps, expected behavior, and actual behavior.
5. Add redacted logs or screenshots when they explain the problem.

For setup questions, use [the support guide](SUPPORT.md).
For security concerns, use [private reporting](SECURITY.md).

## Suggest a feature

Explain the task you cannot complete and who encounters the limitation.
Describe the proposed behavior and alternatives. Keep each request focused on one problem.
Maintainers use issues for discussion and prioritization. A request does not promise an implementation date.

## Improve this tracker

Keep forms short enough for users to complete. Ask only for information needed to reproduce or assess the request.
Preserve the existing support destination. Use synthetic examples and validate form syntax before submitting a pull request.
Use Conventional Commits for repository changes. Include the validation result in the pull request.
